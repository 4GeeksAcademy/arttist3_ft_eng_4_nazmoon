# arttist3_ft_eng_4_nazmoon
This project is a single-page website created to showcase an artist and their work. The goal is to give the artist a professional online presence where visitors can learn about them, explore their career, and see upcoming shows.

The page contains the following sections:

1.Header / Navigation Bar
    .Artist name or logo
    .Home
    .About Me
    .Career
    .Upcoming Shows

2.Hero Section
   .Large introduction to the artist
    .Artist name
    .Short description or tagline
    .Main visual/image

3.About Me
     .Introduction to the artist
      .Background
      .Musical style and interests

4.Career
   .Career information
    .Achievements
    .Music and artistic journey

5.Upcoming Shows
    .Upcoming performances
    .Event dates
    .Event locations

5.Footer
    .Artist information
    .Copyright information
